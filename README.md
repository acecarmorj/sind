# ACEAP — Sistema Administrativo e Portal do Associado

Pacote do sistema com:

- Painel administrativo interno
- Portal do associado
- Catálogo público de associados
- Eventos
- Avisos
- Protocolos
- Carteirinha digital com QR Code

Para atualizar o servidor do sistema, use o arquivo `api.txt` incluído neste pacote.
